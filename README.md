# Plato Enhanced 1.6.18

부산대학교 PLATO의 학습활동 달력과 주차별 자료를 정리하고 NESPA 과제 일정을 함께 보여주는 Chrome·Edge 확장 프로그램입니다.

## 주요 기능

- **학습활동 달력**: 과제·시험의 마감과 제출·완료 상태를 날짜별로 확인합니다. PLATO 활동에는 수동 완료를 표시합니다.
- **NESPA 연동**: 과제 일정과 본인 제출 여부, 점수, 확인된 제출 횟수를 PLATO 달력에서 확인합니다.
- **주차별 자료**: 파일·폴더·과제·시험을 주차별로 모아 열고 활동 상태를 확인합니다.
- **수업 바로가기**: 시간표에 맞춰 현재 수업과 다음 수업의 PLATO 강의실로 이동합니다.

NESPA 과제의 상세 창에서는 시작일·마감과 파일 크기·토큰·실행시간 제한, 최대 제출 횟수, 평가 방식을 확인합니다. 문제 PDF와 샘플 데이터, 제출내역은 원본 NESPA 링크로 엽니다.

## 설치와 업데이트

1. GitHub의 **Code → Download ZIP**으로 소스를 내려받아 압축을 풉니다.
2. `chrome://extensions` 또는 `edge://extensions`에서 개발자 모드를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `manifest.json`이 있는 폴더를 선택합니다.
4. PLATO·NESPA 탭과 열려 있는 확장 설정 페이지를 모두 새로고침합니다.

`plato-enhanced-1.6.18.zip` 배포 파일이 있다면 그 파일의 압축을 풀어 설치해도 됩니다.

업데이트할 때는 사용하던 폴더에 ZIP 내용을 덮어쓰고 확장 관리 화면에서 새로고침하세요. 같은 확장 ID를 유지하면 달력의 수동 완료·접기 설정과 강좌 설정도 유지됩니다. 확장은 한 개만 켜두세요.

## 사용법

PLATO 홈에서 학습활동 달력과 수업 바로가기를 확인합니다. 강좌 페이지에서는 주차별 자료를 모아 볼 수 있습니다. 수업 바로가기는 학생지원시스템에 로그인한 뒤 **시간표 새로고침**을 눌러 연결합니다.

### NESPA 달력 연동

1. 브라우저 확장 아이콘에서 **NESPA 달력 연동**을 켜고 강좌 주소·이름·학년도를 저장합니다.
2. 설정의 **NESPA 로그인 열기**로 NESPA에 직접 로그인합니다.
3. PLATO 홈의 학습활동 달력에서 새로고침을 누릅니다.

기본 강좌는 `https://emerald.pusan.ac.kr/ds2026/`, 자료구조, 2026년입니다. 다른 강좌를 쓰려면 같은 호스트의 강좌 주소와 이름·학년도를 함께 바꾸세요.

NESPA 로그인과 과제 제출, 공지·자료 확인은 원래 NESPA 사이트에서 진행합니다. 세션이 만료되면 다시 로그인한 뒤 달력을 새로고침하세요. 다른 탭에서 로그인·로그아웃한 결과도 다음 달력 새로고침 때 반영됩니다.

## 상태 표시와 저장

- 달력이 보이는 동안 약 10분마다 갱신합니다. 달력을 접거나 탭을 숨기면 자동 갱신을 잠시 멈춥니다. 상세 창의 **상태 새로고침**으로 선택한 활동의 상태를 다시 확인합니다.
- NESPA 기한과 시간표는 한국 시간을 기준으로 표시합니다.
- NESPA의 **제출됨**은 본인 제출내역이 있다는 뜻이며 정답·만점을 의미하지 않습니다. 점수와 확인된 제출 횟수는 별도로 표시합니다.
- 제출내역을 일부만 읽었거나 점수를 확인하지 못한 경우 상세 창에 안내합니다. 확인된 점수만 표시하며 제출 횟수를 알 수 없으면 **확인 불가**로 안내합니다.
- 로그인 만료나 연결 오류가 생기면 제출 상태를 **확인 필요**로 안내합니다. 저장된 공통 일정이 있으면 함께 표시합니다.
- 과제 일정은 복구용으로 저장합니다. 본인 제출 상태·점수·횟수는 메모리에만 유지하며 수동 완료는 PLATO 계정별로 저장합니다.
- NESPA 연동을 끄면 과제 수집과 표시를 중지합니다. 강좌 설정을 바꾸면 해당 강좌의 일정을 조회합니다.

## 개발

JavaScript · HTML/CSS · Chrome Extensions (Manifest V3, Chrome 111+) · Node.js 24 · Python · jsdom

```text
npm ci
npm test
npm run check
npm run test:browser
npm run test:extension
npm run package
python scripts/make-preview.py
```

`artifacts/preview/index.html`에서 익명 예시 데이터로 달력과 설정 화면을 확인합니다.

브라우저 검사는 별도 임시 프로필과 익명 예시 응답을 사용합니다. 실행 파일은 `PLATO_TEST_BROWSER` 환경 변수로 지정하며 결과와 화면은 `artifacts/` 아래에 저장됩니다.

파서 비교 검사는 `PLATO_BENCHMARK_BASELINE`에 비교할 ZIP 경로를 지정한 뒤 `npm run benchmark:parser`로 실행합니다. `npm run check`는 버전·문법과 배포 파일의 연결 관계를 확인합니다.

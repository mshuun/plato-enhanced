# Plato Enhanced 1.6.18

부산대학교 PLATO 달력에 NESPA 과제 일정과 제출 상태를 표시하는 Chrome·Edge 확장 프로그램.

## NESPA는 달력 연동만 제공합니다

NESPA 화면을 PLATO처럼 바꾸는 기능, 자체 과제 관리 화면, 메뉴 삽입, 자동 로그인과 계정 저장을 제거했습니다. NESPA 사이트에 삽입하는 스크립트·스타일·글꼴도 없습니다.

NESPA 과제 일정·제출 상태·점수는 PLATO의 기존 학습활동 달력과 상세 창에서 확인합니다. 제출·공지·자료 확인과 로그인은 원래 NESPA 사이트에서 진행합니다. 기존 PLATO 학습활동 달력·주차별 자료·수업 강의실 바로가기는 사용할 수 있습니다.

## 설치와 업데이트

1. GitHub의 **Code → Download ZIP**으로 소스를 내려받아 압축을 풉니다.
2. `chrome://extensions` 또는 `edge://extensions`에서 개발자 모드를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `manifest.json`이 있는 폴더를 선택합니다.
4. PLATO·NESPA 탭과 열려 있는 확장 설정 페이지를 모두 새로고침합니다.

`plato-enhanced-1.6.18.zip` 배포 파일이 있다면 그 파일의 압축을 풀어 설치해도 됩니다.

기존 설치를 업데이트하려면 사용하던 폴더에 ZIP 내용을 덮어쓰고 확장 관리 화면에서 새로고침하세요. 같은 확장 ID를 유지해야 기존 달력 완료·접기 설정과 강좌 설정이 보존됩니다. 기존 확장과 새 확장을 동시에 켜지 마세요.

이미 열려 있던 NESPA 탭의 화면 변경은 페이지를 새로고침하면 사라집니다. 새 버전은 NESPA 페이지에 코드를 삽입하지 않습니다. 업데이트 시 이전 자동 로그인 설정·로그인 상태와 확장 전용 계정 저장소를 정리합니다.

## 달력 연동 사용법

1. 브라우저 확장 아이콘에서 **NESPA 달력 연동**을 켜고 강좌 주소·이름·학년도를 저장합니다.
2. 설정의 **NESPA 로그인 열기**로 원래 NESPA 사이트에 직접 로그인합니다.
3. PLATO 홈의 학습활동 달력에서 새로고침을 누릅니다.

기본 강좌는 `https://emerald.pusan.ac.kr/ds2026/`, 자료구조, 2026년입니다. 다른 강좌를 사용하려면 같은 호스트의 주소·이름·연도를 함께 바꿉니다. 연동을 끄면 NESPA 과제 수집과 달력 표시를 중지합니다.

확장은 로그인된 브라우저 세션으로 과제 목록과 본인 제출내역을 읽습니다. 계정·비밀번호를 저장하거나 로그인 폼을 제출하지 않으며, 백그라운드 로그인 탭도 열지 않습니다. 세션이 만료되면 NESPA에 직접 다시 로그인한 뒤 달력을 새로고침하세요. 다른 탭에서 로그인·로그아웃해도 NESPA 페이지에는 접근하지 않으므로, 해당 변경은 다음 달력 새로고침 때 반영됩니다.

## 일정과 제출 상태

- PLATO 달력이 보이는 동안 약 10분마다 갱신하며, 수동 새로고침은 이전 제출 상태 캐시를 건너뛰고 확인합니다. 달력을 접거나 탭을 숨기면 자동 갱신을 쉽니다.
- NESPA 번호의 앞자리 0을 보존하고 강좌 연도·한국 시간으로 기한을 해석합니다.
- **제출됨**은 본인의 제출내역이 있다는 뜻이며 정답·만점을 의미하지 않습니다. 점수와 확인된 제출 횟수는 별도로 표시합니다.
- 상세 창에는 원본 과제의 시작일·마감과 토큰·파일 크기·실행시간·최대 제출 횟수·평가 방식을 표시합니다. 빈 정보는 추측하지 않습니다.
- 로그인 만료나 연결 실패를 미제출로 표시하지 않습니다. 저장된 일정이 있으면 제출 상태를 **확인 필요**로 표시합니다.
- 개인 제출 상태·점수·횟수는 지속 저장하지 않습니다. 공통 과제 일정만 복구용으로 보관합니다.
- NESPA 제출과 자료 열기는 상세 창의 원본 NESPA 링크를 사용합니다. 제출 문제·언어·파일은 NESPA에서 직접 선택하고 확인하세요.
- NESPA 연결 실패와 PLATO 연결 실패는 각각 표시하며 다른 사이트의 정상 일정은 유지합니다.
- NESPA 목록의 권한·연결 오류를 빈 목록이나 미제출로 판단하지 않습니다. 목록 전체를 읽지 못하면 저장된 공통 일정만 표시합니다.
- 연동을 끄거나 강좌 설정을 변경하면 진행 중인 NESPA 조회도 중단합니다.

수업 바로가기는 학생지원시스템 로그인 후 사용할 수 있습니다. 연결되지 않으면 로그인한 뒤 **시간표 새로고침**을 누르세요.

## 1.6.18 수정 사항

- 달력 이벤트 번호가 없는 시험 등도 유효한 강좌 번호가 있으면 상세 창에서 완료 상태를 새로 확인합니다. 기존에는 강좌 활동 현황으로 조회할 수 있어도 새로고침 버튼과 열린 창의 정기 갱신이 비활성화됐습니다.
- 수동 완료 설정을 유지하면서 강좌 활동 현황의 최신 결과를 달력·상세 창에 함께 반영합니다. 사용할 조회 번호가 없는 활동은 자동 요청을 시작하지 않습니다.
- 1.6.17의 늦은 상세 응답 차단·저장 후 키보드 위치 보존을 재검증했습니다. 인증 만료 전의 늦은 성공·인증 실패가 복구 후 진행 중인 새 요청을 중단하지 않는 검사도 추가했습니다.
- 실제 설치 확장 검사에 이벤트 번호 없는 시험의 키보드 새로고침, 강좌 조회 주소와 입력 위치 보존을 추가했습니다.

## 1.6.17 수정 사항

- 수동 완료 저장을 기다리는 동안 닫기 버튼 등으로 옮긴 키보드 위치를 유지합니다. 저장·실패 처리가 끝났을 때 입력 위치를 빼앗지 않으며, 버튼 비활성화로 위치를 잃은 경우에는 저장 버튼으로 돌아갑니다.
- 다른 설정 창에서 NESPA 연동 설정을 바꿔 달력이 갱신되더라도, 이전 PLATO 상세 응답이 새 제목·제출 상태를 덮지 않습니다. 갱신 또는 종료로 오래된 결과가 된 상세 응답은 호출자에게도 적용하지 않습니다.
- NESPA 인증 만료가 확인되면 백그라운드에서 진행 중인 이전 조회도 중단합니다. 재로그인 후 재조회가 이전 세션의 요청에 합류하지 않으며, 늦은 성공·인증 실패 응답이 복구한 상태를 바꾸지 못하도록 했습니다.
- 앞선 버전의 저장 후 읽기 실패·잘못된 마감 시각 방어를 유지하면서 키보드 위치, 설정 변경 중 상세 응답, 인증 만료 후 요청 분리를 추가로 검사했습니다.

## 1.6.16 수정 사항

- 수동 완료 저장에 성공한 뒤 저장소 재조회만 실패할 때, 상세 창과 달력의 완료 표시가 달라지는 문제를 수정했습니다. 저장 확인 즉시 달력에 반영하며, 재조회에서 더 최신 값이 확인되면 상세 창도 그 값을 표시합니다.
- 저장 실패·계정 전환 중에는 완료 표시를 임의로 바꾸지 않습니다. 저장 전 시작한 오래된 읽기 결과가 완료 표시를 되돌리는 경우도 검사했습니다.
- PLATO의 잘못된 상세 응답에 날짜로 표현할 수 없는 마감 시각이 들어와도 기존 마감일을 유지합니다. 사용 가능한 다른 시각이 있으면 그 값을 사용하며, 유효한 시각이 없는 일정은 다른 정상 일정과 분리해 제외합니다.
- 1.6.15의 주소·텍스트 처리 최적화를 정리 전 코드와 혼합 일정·상세 응답·특수문자 입력 1,218건으로 추가 비교해 결과 일치를 확인했습니다. 기존 성능 개선을 유지하고 실제 설치 확장 검사에 저장 후 읽기 실패와 잘못된 상세 시각을 추가했습니다.

## 1.6.15 수정 사항

- 사용하지 않는 갱신 시각·메서드·공개 함수·설정 화면 스타일을 제거하고, 제출 상태와 강좌 완료 상태의 공통 캐시 처리를 합쳤습니다. 수동 완료 저장 뒤의 불필요한 저장소 조회도 줄였습니다.
- PLATO 주소를 한 번 해석한 결과를 재사용하며, HTML이 없는 제목·강좌명은 DOM 문서로 변환하지 않습니다. 날짜 표시 함수를 공통으로 사용하고 명시한 시간대의 포맷터를 재사용합니다. 브라우저 시간대가 바뀌는 경우의 기본 표시도 유지합니다.
- 정리 직전 코드와 같은 입력으로 비교했을 때 일정 200개·할 일 400개의 주소 해석은 8,000회에서 1,000회로 줄었습니다. 일정 200개의 날짜 표시 포맷터 생성은 유효한 시간대에서 842회에서 3회로 줄었으며 표시 결과는 일치했습니다. 실제 서버 속도를 측정한 수치는 아닙니다.
- NESPA 제출내역의 중복 번호를 한 번만 세고, 일부 내역이나 점수를 확인할 수 없으면 상세 창에 안내합니다. 확인된 제출 여부는 유지하며 불확실한 횟수·최고 점수는 표시하지 않습니다.
- 시간표에서 번호·이름이 충돌하는 강좌를 다른 강좌로 연결하지 않습니다. 모바일 상세 창의 안내문과 하단 버튼이 잘리는 문제도 수정했습니다.
- 배포 파일의 연결 관계 검사와 파서·날짜 표시·설정 스타일의 정리 전후 비교를 추가하고, 브라우저 검사 도구의 중복 실행 코드를 합쳤습니다.

## 1.6.14 수정 사항

- 시스템 시계가 뒤로 바뀌어도 이전 일정·제출 상태 캐시가 계속 유효한 것으로 남지 않도록 했습니다. 현재보다 미래에 조회한 것으로 기록된 PLATO·NESPA 캐시는 다시 확인합니다.
- 달력, 열린 상세정보, 시간표와 주차별 자료의 자동 갱신도 시계 변경 때문에 미뤄지지 않도록 수정했습니다. 갱신 후에는 정상 간격으로 돌아가며 숨겨진 화면의 조회 제한은 유지합니다.
- 상세정보의 다음 갱신 대기 시간이 시계 역행만큼 길어지는 문제를 수정했습니다. 10분 캐시의 만료 경계, 조회 실패 후 복구와 반복 재조회 방지를 함께 검증했습니다.
- 테스트에서는 확장 실행 영역의 모의 시계만 변경합니다. 컴퓨터의 시스템 시계나 사용자의 브라우저 프로필은 변경하지 않습니다.

## 1.6.13 수정 사항

- 주차별 자료·활동 상태 응답을 받을 때 화면이 숨겨졌거나 제거됐는지 다시 확인합니다. 늦은 응답이 화면을 바꾸거나 후속 조회를 시작하지 않도록 중단하고, 화면으로 돌아오면 다시 조회합니다. 제거된 자료 화면은 원래 강좌 화면을 복구합니다.
- 시간표 갱신 중에도 선택한 강의실 링크와 스크롤 위치를 유지합니다. 같은 강좌의 수업이 여러 개면 선택한 수업을 따라가며, 수업이 사라졌으면 수업 바로가기 제목으로 돌아갑니다. 조회 중 다른 곳으로 옮긴 포커스는 바꾸지 않습니다.
- 키보드로 시간표를 새로고침할 때 조회 안내문에 잠시 포커스를 옮기고, 조회가 끝나면 새로고침 버튼으로 돌려줍니다. 시간표 보조 글자의 대비와 제목·안내문의 포커스 표시도 개선했습니다.
- 실제 설치 확장 검사에 늦은 주차별 응답, 시간표 키보드 조작과 390px 화면 검증을 추가했습니다.

## 1.6.12 수정 사항

- 같은 달의 조회가 겹쳐 응답이 역순으로 도착해도 최신 일정 캐시가 이전 결과로 돌아가지 않습니다. 일반 조회는 진행 중인 최신 조회를 기다리며, 명시적인 새로고침은 새 요청을 시작합니다.
- 달력 새로고침이 실패하면 이전 캐시를 새 결과처럼 다시 표시하지 않고 다음 조회에서 재시도합니다. 다른 달의 요청과 캐시는 독립적으로 유지합니다.
- 제출 상태·강좌 활동 현황을 새로고침하면 진행 중인 이전 요청에 합류하지 않고 다시 조회합니다. 이전 호출에도 최신 결과를 전달해 달력과 상세 화면의 상태가 뒤늦게 되돌아가지 않게 했습니다.
- 계정 변경·종료 후 이전 요청이 새 계정의 결과나 캐시를 바꾸지 못하도록 차단합니다. 실제 설치 확장 검사에 지연된 달력 응답과 역순 HTTP 상태 응답을 추가했습니다.

## 1.6.11 수정 사항

- 일정이 많을 때 할 일 주소를 반복해서 해석하던 작업을 줄였습니다. 번호·활동별로 필요한 후보를 찾아 연결하며 기존 우선순위와 검증 조건은 유지합니다.
- 강좌 상태를 일괄 반영할 때 캐시와 달력을 항목마다 다시 만들지 않고 한 번에 갱신합니다. 다른 강좌와 NESPA 상태는 유지합니다.
- 전체 달력을 새로고침할 때도 선택한 활동·더보기 스크롤·툴바의 키보드 위치를 복원합니다. 조회 중 다른 곳으로 옮긴 포커스는 바꾸지 않으며, 실패하면 오류 안내와 다시 시도 버튼을 사용할 수 있습니다.
- 조회 중에는 이전 개인 상태를 계속 숨기고, 새 결과를 받은 뒤에만 활동으로 돌아갑니다.
- 대량 일정의 실제 설치 확장 검사와 이전 버전 대비 파서 성능·결과 비교 도구를 추가했습니다.

## 1.6.10 수정 사항

- 활동 번호가 중복되거나 잘못된 PLATO 링크를 다른 과제의 상태 조회에 사용하지 않습니다. 계정 정보가 들어간 주소도 사용하지 않으며 일정 제목·기한은 유지합니다.
- 서로 다른 활동이 같은 일반 달력 주소를 공유할 때 일정 하나가 사라지는 문제를 수정했습니다.
- 할 일 데이터의 잘못된 활동·강좌 정보나 빈 활동 번호 때문에 다른 과제의 마감·제출 상태가 적용되는 문제도 수정했습니다.
- 형식이 잘못된 활동 번호·시각을 다른 일정의 번호나 마감으로 해석하지 않도록 했습니다.
- 활동 유형 정보가 오래됐거나 잘못되어도 유효한 원본 활동 주소를 기준으로 과제·시험 유형을 표시합니다.
- 선택한 일정과 번호·활동이 다른 상세 응답을 적용하지 않습니다. 상세 응답이 비어 있는 경우에도 조회 실패 안내를 표시하며, 원래 과제의 제출 상태는 별도로 확인합니다.
- 실제 설치 확장 검사에 잘못된 링크·공통 달력 주소·유형 불일치·다른 일정의 상세 응답을 추가했습니다.

## 1.6.9 수정 사항

- 여러 설정 창에서 서로 다른 항목을 저장해도 다른 창의 변경을 지우지 않습니다. 편집한 항목만 저장하며 창 사이의 저장 작업을 순서대로 처리합니다.
- 같은 항목을 동시에 바꾸면 오래된 값으로 덮어쓰지 않고 현재 저장된 값을 안내합니다. 입력은 유지하므로 확인한 뒤 다시 저장할 수 있습니다.
- 다른 창의 변경은 편집하지 않은 항목에 반영합니다. 입력 중인 값·커서 위치는 유지하며, 저장된 설정을 처음 불러오지 못한 경우에는 확인되지 않은 값으로 저장하지 않습니다.
- 설정 충돌 안내를 저장 버튼 앞에 배치하고 작은 안내 문구·버튼의 글자 대비를 높였습니다.
- 실제 설치 확장 검사에 두 설정 탭의 동시 저장과 충돌, NESPA 로그인 만료·연결 실패·복구 시나리오를 추가했습니다.

## 1.6.8 수정 사항

- 주차별 강의 자료를 갱신해도 선택 중인 자료 링크·새 탭 열기 버튼의 키보드 위치와 스크롤을 유지합니다. 같은 자료가 여러 주차에 있어도 원래 주차의 위치로 돌아갑니다.
- 선택한 자료가 삭제되면 해당 주차 제목으로, 주차까지 사라지면 강의 자료 제목으로 이동합니다. 조회를 기다리는 동안 다른 입력란으로 옮긴 포커스는 바꾸지 않습니다.
- 실제 설치 확장 검증에 시간표 조회·강좌 연결·계정별 저장, 해외 시간대에서의 한국 날짜 표시, 주차별 과제·퀴즈 조회와 모바일 키보드 이동을 추가했습니다.

## 1.6.7 수정 사항

- PLATO 할 일 상태 응답의 형식이 잘못되면 정상적인 빈 목록으로 처리하지 않고 일부 상태를 확인하지 못했다는 안내를 표시합니다.
- 다음 페이지 조회 실패나 시간 초과가 발생해도 앞서 받은 할 일 상태를 유지하며, 늦게 도착한 응답은 더 이상 반영하지 않습니다.
- 월별 일정 조회가 실패하면 불필요한 추가 페이지 요청과 모듈 대기를 중단합니다. 월별 응답이 없을 때 빈 달력을 정상 조회로 표시하지 않습니다.
- 임시 Chrome에 확장을 실제 설치하는 통합 검사를 추가했습니다. 페이지 실행 영역 분리·백그라운드 요청·수동 완료 보존·설정 변경 반영을 익명 로컬 응답으로 확인합니다.

## 1.6.6 수정 사항

- NESPA 로그인 만료를 확인하면 달력과 열린 상세 창의 제출 상태·점수·횟수를 확인 필요로 바꾸고 다시 로그인할 방법을 안내합니다. 공통 일정과 PLATO 활동은 유지합니다.
- 만료 전에 시작한 조회가 늦게 끝나도 이전 제출 상태를 캐시에 되살리지 않으며, 오래된 오류가 새 로그인 뒤의 정상 결과를 지우지 않도록 했습니다.
- 만료 전 대기 중이던 제출 상태 조회는 새 요청을 보내지 않고 폐기합니다. 진행 중인 요청은 늦게 도착한 결과를 무시하며 동시 조회 제한을 유지합니다.
- 같은 활동의 상세 창을 닫았다 다시 열면 최신 조회만 화면을 갱신합니다. PLATO의 오래된 상세 응답이 추가 상태 조회를 시작하는 것도 막았습니다.
- 저장된 일정의 강좌 주소·학년도가 현재 설정과 다르면 해당 복구 데이터를 사용하지 않습니다.

## 1.6.5 수정 사항

- 달력 갱신 중에도 날짜별 ‘더보기’ 목록과 키보드 위치·스크롤을 유지합니다. 목록 뒤쪽 활동의 상세 창을 닫으면 해당 활동으로 돌아갑니다.
- 좁은 화면에서 팝오버가 잘리지 않도록 표시 영역에 맞추고, 창 크기를 바꿔도 선택한 활동이 보이도록 했습니다.
- 설정을 불러오거나 저장하는 동안 입력과 중복 저장을 막아 편집 내용이 뒤늦은 응답으로 덮이지 않도록 했습니다. 저장 오류가 나면 입력을 유지하고 다시 시도할 수 있습니다.
- 빈 강좌명이나 범위를 벗어난 학년도를 기본값으로 바꿔 저장하던 문제를 수정했습니다.
- 연도를 생략한 마감일이 다음 해의 2월 29일일 때 일정을 누락하는 문제를 수정했습니다.

## 1.6.4 수정 사항

- 주차별 자료에서 파일 팝업 주소 하나가 잘못되어도 다른 파일·과제까지 갱신에 실패하지 않도록 했습니다. 열 수 없는 팝업은 원래 파일 링크로 돌아갑니다.
- 과제·퀴즈 상태 자동 조회에는 활동 번호만 사용합니다. 원본 링크의 사용자·그룹·응시·편집·세션 매개변수를 자동 조회에 전달하지 않으며, 응답 주소가 달라지면 상태를 확인 불가로 표시합니다.
- 잘못되거나 중복된 활동 번호와 계정 정보가 포함된 링크는 자동으로 조회하지 않고 제목·안내를 유지합니다. 활동 유형은 유효한 원본 주소를 기준으로 확인합니다.
- 시간표 화면이 숨겨지거나 제거된 동안 도착한 응답은 저장·표시하지 않고 화면 복귀 시 다시 조회합니다. 화면이 제거된 상태에서 새 시간표 조회를 시작하지 않습니다.
- 강좌 목록이 바뀐 뒤 이전 조회가 실패하더라도 새 목록의 시간표 조회가 10분간 지연되지 않도록 했습니다.

## 1.6.3 수정 사항

- 활동 현황이 완료여도 실제 제출 상태가 미제출·초안·재제출 필요이면 달력과 상세 창에 할 일로 표시합니다. 해당 상태와 마감 임박·경과 여부를 함께 표시하며 수동 완료 설정은 유지합니다.
- 주차별 자료의 과제 제출·채점 상태는 본인 상태 영역에서만 읽습니다. 달력과 같은 파서를 사용해 과제 설명·이전 제출내역의 문구를 현재 상태로 오인하지 않도록 했습니다.
- 퀴즈 설명 속 예시 응시 기록·점수·활동 완료 문구를 본인 상태에서 제외했습니다.
- 상세 조회에 실패하거나 새 응답에 제출·채점 정보가 없으면 이전 완료·점수를 되살리지 않고 확인 불가로 표시합니다.

## 1.6.2 수정 사항

- PLATO 완료 상태를 다시 확인하지 못했을 때 이전 활동 현황의 ‘완료’가 남는 문제를 수정했습니다. 새로 확인된 완료 상태와 수동 완료 설정은 유지합니다.
- 월별 캐시를 사용하기 전에 PLATO 페이지의 사용자 정보를 확인합니다. 계정 변경을 확인하면 이전 일정·제출 상태 캐시를 지우고, 진행 중인 상태 조회와 늦게 도착한 결과를 폐기합니다.
- PLATO 계정이 바뀌면 이전 계정의 상세 창을 닫아 완료 설정이 섞이지 않게 했습니다.
- 다른 탭의 로그인 변경을 현재 PLATO 페이지가 아직 반영하지 않았다면 페이지를 새로고침하세요.

## 1.6.1 수정 사항

- 권한·연결 오류 문구를 정상적인 빈 목록으로 오인해 과제가 사라지거나 미제출로 표시되는 문제를 수정했습니다.
- 과제 번호가 11자리 이상일 때 제출내역 조회가 거부되는 문제를 수정했습니다. 앞자리 0을 포함해 최대 40자리까지 그대로 조회합니다.
- 목록을 읽지 못할 때 저장된 일정 복구를 보완하고, 연동 해제·강좌 변경 시 진행 중인 요청을 취소합니다.

## 개발

JavaScript · HTML/CSS · Chrome Extensions (Manifest V3, Chrome 111+) · Node.js 24 · jsdom

```text
npm ci
npm test
npm run check
npm run test:browser
npm run test:extension
npm run benchmark:parser
npm run package
python scripts/make-preview.py
```

`artifacts/preview/index.html`을 열면 익명 예시 데이터로 달력과 연동 설정을 확인할 수 있습니다. 개발용 데이터·의존성·미리보기는 배포 ZIP에 포함하지 않습니다.

`test:browser`는 설치된 Chrome 또는 Edge를 별도 임시 프로필의 헤드리스 모드로 실행해 미리보기의 키보드 이동·포커스 복원·모바일 팝오버·설정 저장을 검사합니다. 다른 Chromium 실행 파일은 `PLATO_TEST_BROWSER` 환경 변수로 지정합니다. 기존 브라우저 프로필이나 로그인 세션은 사용하지 않으며 결과와 화면은 `artifacts/browser-smoke/`에 저장합니다.

`test:extension`은 별도 임시 프로필에 현재 확장을 로드해 실제 Manifest V3 실행 영역·서비스 워커·확장 저장소와 설정 페이지의 연결, 시간표, 주차별 자료와 과제·퀴즈 상태를 검사합니다. 호놀룰루 시간대에서도 달력과 시간표가 한국 날짜를 표시하는지 확인합니다. `Extensions.loadUnpacked` 디버깅 API가 있는 Chromium이 필요하며 Chrome 157에서 확인했습니다. 검사 대상 탭과 확장 워커의 HTTPS 요청은 모두 로컬 예시로 응답하고 예상하지 않은 주소도 외부로 전달하지 않습니다. 결과와 화면은 `artifacts/extension-smoke/`에 저장합니다. 실제 PLATO·NESPA 로그인 세션과 서버 응답을 검증하는 검사는 아닙니다.

`benchmark:parser`는 보관한 `plato-enhanced-1.6.14.zip`과 현재 코드를 같은 모의 입력으로 비교합니다. URL·DOM·날짜 포맷터 생성 횟수, 파서·날짜 표시 결과와 설정 화면 스타일의 일치 여부를 기록합니다. 표시한 시간은 네트워크를 사용하지 않는 Node VM·JSDOM 실험값입니다. 비교 ZIP은 `PLATO_BENCHMARK_BASELINE`으로 지정할 수 있고 결과는 `artifacts/parser-benchmark.json`에 저장합니다. `check`는 버전·문법과 함께 Manifest 진입점에서 모든 배포 코드·스타일로 연결되는지도 검사합니다.

비교용 이전 버전 ZIP은 저장소에 포함하지 않습니다. `benchmark:parser`를 실행하려면 해당 ZIP을 따로 준비하세요.

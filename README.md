# Plato Enhanced

부산대학교 PLATO를 더 편하게 쓰기 위한 Chrome·Edge 확장 프로그램.

- 학습활동 달력과 마감·제출·완료 상태 표시
- 주차별 자료와 폴더 바로 열기
- 과제·퀴즈의 제출 상태와 공개된 점수 확인
- 현재 수업 강의실 바로가기

## 설치

1. **Code → Download ZIP**으로 내려받아 압축을 풉니다.
2. `chrome://extensions` 또는 `edge://extensions`에서 개발자 모드를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `manifest.json`이 있는 폴더를 선택합니다.
4. PLATO 페이지를 새로고침합니다.

업데이트할 때는 기존 폴더에 덮어쓰고 확장을 새로고침하면 저장된 설정을 유지할 수 있습니다.

수업 바로가기는 학생지원시스템 로그인 후 사용할 수 있습니다. 연결되지 않으면 학생지원시스템에 로그인하고 **시간표 새로고침**을 누르세요.

## 개발

Node.js 22 이상에서 `npm ci` 후 `npm test`를 실행합니다.
